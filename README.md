# Security Operations Center (SOC) Learning Portfolio

A practical learning space for developing foundational SOC analyst skills. This repository focuses on understanding security alerts, reviewing logs, investigating suspicious activity, and documenting findings in a clear, repeatable way.

## Learning Focus

- Log collection and basic analysis
- SIEM concepts and alert triage
- Network traffic investigation
- Incident-response fundamentals
- Detection logic and false-positive awareness
- Clear investigation notes and escalation summaries

## Suggested Investigation Workflow

1. **Understand the alert** — identify the source, timestamp, affected asset, and detection reason.
2. **Gather context** — review relevant logs and available network or endpoint evidence.
3. **Validate the signal** — distinguish suspicious activity from expected behaviour where possible.
4. **Assess impact** — record what is known, what remains uncertain, and the potential risk.
5. **Document findings** — capture evidence, steps taken, and recommended next actions.
6. **Escalate appropriately** — follow the lab or organisation's incident-handling process.

## Tools and Concepts

Learning may involve SIEM platforms such as Wazuh, network analysis with Wireshark, network discovery with Nmap, and intrusion-detection concepts using Suricata. Tool usage and results should be documented per exercise.

## Project Documentation Standard

For each lab, aim to include:

- Objective and scope
- Environment and data source
- Tools and configuration
- Investigation steps
- Findings and supporting evidence
- Limitations, false-positive considerations, and lessons learned

## Status

This is a learning portfolio, not a claim of professional SOC experience or a production monitoring service. Content will evolve as new exercises are completed and reviewed.

## Responsible Use

Use only authorised lab systems and approved datasets. Protect sensitive logs and redact credentials, tokens, personal data, and other secrets before publishing.
